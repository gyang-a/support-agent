# RAG 检索评测：500 道问题与标准答案

> 所有产品与参数均为虚构测试数据。标准答案必须能由标注的证据切片直接支持。

## Aurora X1（`aurora_x1`）

### 1. Aurora X1 的屏幕/形态和识别码或硬件型号是什么？

**标准答案：** 6.10 英寸 OLED，机身识别码前缀 AX1-CN。

**标准位置：** `aurora_x1::1 产品概览`

**难负例：** `aurora_x1_pro`

### 2. Aurora X1 的供电或充电功率与端口规则是什么？

**标准答案：** 最大有线充电功率为 45 W，仅 USB-C1 口支持快充。

**标准位置：** `aurora_x1::1 产品概览`

**难负例：** `aurora_x1_pro`

### 3. Aurora X1 允许或建议的充电、工作温度范围是多少？

**标准答案：** 允许充电环境温度为 0 至 35 摄氏度。

**标准位置：** `aurora_x1::1 产品概览`

**难负例：** `aurora_x1_pro`

### 4. Aurora X1 首次设置时第一步应该怎么做？

**标准答案：** 首次开机后长按电源键 3 秒，再扫描包装内的设备迁移二维码。

**标准位置：** `aurora_x1::2 初次设置与功能`

**难负例：** `aurora_x1_pro`

### 5. Aurora X1 的特殊模式有什么启用条件或限制？

**标准答案：** 护眼阅读模式只能在刷新率设置为 60 Hz 时启用。

**标准位置：** `aurora_x1::2 初次设置与功能`

**难负例：** `aurora_x1_pro`

### 6. Aurora X1 出现文档中的特定状态灯或错误码代表什么？

**标准答案：** 出现 E17 且充电图标闪烁时，表示 USB-C 端口检测到液体。

**标准位置：** `aurora_x1::5 故障诊断`

**难负例：** `aurora_x1_pro`

### 7. Aurora X1 无响应时应如何按文档执行复位或强制重启？

**标准答案：** 同时按住电源键和音量减键 12 秒可执行强制重启。

**标准位置：** `aurora_x1::5 故障诊断`

**难负例：** `aurora_x1_pro`

### 8. Aurora X1 的协议、端口或网络兼容性限制是什么？

**标准答案：** 支持 Wi-Fi 6，不支持 Wi-Fi 7 的 320 MHz 信道。

**标准位置：** `aurora_x1::3 供电与兼容性`

**难负例：** `aurora_x1_pro`

### 9. Aurora X1 的保修期限或主要除外条件是什么？

**标准答案：** 电池在 12 个月内且健康度低于 80% 时可申请检测，不保证直接换新。

**标准位置：** `aurora_x1::6 保修与服务`

**难负例：** `aurora_x1_pro`

### 10. 使用 Aurora X1 时文档明确禁止或要求的安全事项是什么？

**标准答案：** 端口进液后至少静置 4 小时，禁止使用热风机烘干。

**标准位置：** `aurora_x1::7 安全要求`

**难负例：** `aurora_x1_pro`
