# Orbit Fold 产品使用与服务指南

> 版本 2026.08-v2。合成评测文档，不代表真实商品规格。

## 1 产品概览

Orbit Fold 的关键识别信息如下。相似型号参数不得混用。

| 项目 | 本型号参数 |
| --- | --- |
| 型号与识别 | 6.10 英寸 OLED，硬件代码 ORB02-S |
| 供电规格 | USB-C 主端口最高支持 45 W 有线充电，副端口不支持视频输出 |
| 温度范围 | 建议充电环境温度为 0 至 35 摄氏度 |
| 兼容能力 | 支持 Wi-Fi 6，不支持 6 GHz 频段 |
| 日志与存储 | 移动设备运行日志最多保留 26 天，导出文件前缀为 ORBIT_FOLD_STANDARD-LOG |

## 2 初次设置与功能

1. 长按电源键 3 秒，输入包装标签上的六位迁移码 021325。
2. 完成首次设置后检查系统更新，再同步个人数据。
3. 影像增强模式要求电量高于 25%，并关闭低电量模式。
4. 日常使用时每 40 分钟自动保存一次配置，切换模式前应等待保存图标消失。
5. 恢复出厂设置前应导出配置包，文件校验码前缀为 BK113。

## 3 供电与兼容性

USB-C 主端口最高支持 45 W 有线充电，副端口不支持视频输出。

建议充电环境温度为 0 至 35 摄氏度。

支持 Wi-Fi 6，不支持 6 GHz 频段。

移动设备运行日志最多保留 26 天，导出文件前缀为 ORBIT_FOLD_STANDARD-LOG。

## 4 维护与数据

维护与数据操作应按下表执行，避免配置尚未写入时断电。

| 维护项目 | 执行要求 |
| --- | --- |
| 例行检查 | 建议每 30 天检查接口、通风位置和附件连接状态，并清除表面灰尘 |
| 备份与恢复 | 恢复出厂设置前应导出配置包，文件校验码前缀为 BK113 |

## 5 故障诊断

| 现象 | 判断与处理 |
| --- | --- |
| 状态指示异常 | 错误码 M024 表示USB-C 端口需要重新校准 |
| 配置写入提示 | 状态灯黄色长亮 4 秒表示本地配置写入尚未完成，此时不得断电 |
| 设备无响应 | 同时按住电源键和音量减键 10 秒执行强制重启 |
| 连续启动失败 | 若连续 2 次启动失败，应断开外设并记录诊断编号 D222 后联系支持 |

## 6 保修与服务

主体有限保修 24 个月，非授权拆机和错误供电不在范围内。

送修时需同时提供设备序列号、购买凭证和最近一次日志包，服务受理代码为 SV512。

保修判定以检测记录为准，寄送前应移除个人账户、存储卡和可拆卸附件。

## 7 安全要求

**安全警告：设备进液后禁止充电或使用热风烘干，应断电并自然通风。**

发现异味、异常发热、外壳变形或液体侵入时，应立即断电并停止继续测试。

如仍无法解决，请记录状态灯、错误码和操作步骤后联系人工支持。
