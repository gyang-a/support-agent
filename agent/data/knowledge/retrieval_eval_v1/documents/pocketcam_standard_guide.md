# PocketCam V2 产品使用与服务指南

> 版本 2026.08-v2。合成评测文档，不代表真实商品规格。

## 1 产品概览

PocketCam V2 的关键识别信息如下。相似型号参数不得混用。

| 项目 | 本型号参数 |
| --- | --- |
| 型号与识别 | APS-C无反相机，机身代码 POC16-S |
| 供电规格 | USB-C 供电最高 54 W，连续录像需使用标有 PD 的端口 |
| 温度范围 | 连续录像环境温度建议为 0 至 35 摄氏度 |
| 兼容能力 | 支持 UHS-I，不支持外录 RAW 视频 |
| 日志与存储 | 影像设备运行日志最多保留 20 天，导出文件前缀为 POCKETCAM_STANDARD-LOG |

## 2 初次设置与功能

1. 装入电池后长按菜单键 3 秒，再执行日期和传感器初始化。
2. 完成首次设置后检查系统更新，再同步个人数据。
3. 高码率录像要求存储卡持续写入不低于 248 MB/s。
4. 日常使用时每 20 分钟自动保存一次配置，切换模式前应等待保存图标消失。
5. 恢复出厂设置前应导出配置包，文件校验码前缀为 BK141。

## 3 供电与兼容性

USB-C 供电最高 54 W，连续录像需使用标有 PD 的端口。

连续录像环境温度建议为 0 至 35 摄氏度。

支持 UHS-I，不支持外录 RAW 视频。

影像设备运行日志最多保留 20 天，导出文件前缀为 POCKETCAM_STANDARD-LOG。

## 4 维护与数据

维护与数据操作应按下表执行，避免配置尚未写入时断电。

| 维护项目 | 执行要求 |
| --- | --- |
| 例行检查 | 建议每 90 天检查接口、通风位置和附件连接状态，并清除表面灰尘 |
| 备份与恢复 | 恢复出厂设置前应导出配置包，文件校验码前缀为 BK141 |

## 5 故障诊断

| 现象 | 判断与处理 |
| --- | --- |
| 状态指示异常 | 机身灯连续闪烁 C16 节奏表示传感器防抖需要校准 |
| 配置写入提示 | 状态灯黄色长亮 2 秒表示本地配置写入尚未完成，此时不得断电 |
| 设备无响应 | 关机取下电池 36 秒，再按住快门键装回电池 |
| 连续启动失败 | 若连续 2 次启动失败，应断开外设并记录诊断编号 D250 后联系支持 |

## 6 保修与服务

主体有限保修 12 个月，非授权拆机和错误供电不在范围内。

送修时需同时提供设备序列号、购买凭证和最近一次日志包，服务受理代码为 SV540。

保修判定以检测记录为准，寄送前应移除个人账户、存储卡和可拆卸附件。

## 7 安全要求

**安全警告：清洁传感器时镜头卡口必须朝下，禁止使用罐装高压气体。**

发现异味、异常发热、外壳变形或液体侵入时，应立即断电并停止继续测试。

如仍无法解决，请记录状态灯、错误码和操作步骤后联系人工支持。
