# ChargeHub 65 产品使用与服务指南

> 版本 2026.08-v2。合成评测文档，不代表真实商品规格。

## 1 产品概览

ChargeHub 65 的关键识别信息如下。相似型号参数不得混用。

| 项目 | 本型号参数 |
| --- | --- |
| 型号与识别 | 双口氮化镓充电器，型号 CH65-G2 |
| 供电规格 | 单独使用 USB-C1 时最高 65 W，双口同时使用时分配为 45 W 加 20 W |
| 温度范围 | 满载工作允许外壳表面温度最高 62 摄氏度 |
| 兼容能力 | USB-C1 支持 PD 3.0 与 PPS，USB-A 口不支持 PPS |
| 日志与存储 | 供电设备运行日志最多保留 22 天，导出文件前缀为 CHARGEHUB_65-LOG |

## 2 初次设置与功能

1. 先连接设备端，再将充电器插入墙上插座，可减少协议重新协商。
2. 完成首次设置后检查系统更新，再同步个人数据。
3. 低电流模式需长按侧键 2 秒，指示灯变为绿色常亮。
4. 日常使用时每 20 分钟自动保存一次配置，切换模式前应等待保存图标消失。
5. 恢复出厂设置前应导出配置包，文件校验码前缀为 BK109。

## 3 供电与兼容性

单独使用 USB-C1 时最高 65 W，双口同时使用时分配为 45 W 加 20 W。

满载工作允许外壳表面温度最高 62 摄氏度。

USB-C1 支持 PD 3.0 与 PPS，USB-A 口不支持 PPS。

供电设备运行日志最多保留 22 天，导出文件前缀为 CHARGEHUB_65-LOG。

## 4 维护与数据

维护与数据操作应按下表执行，避免配置尚未写入时断电。

| 维护项目 | 执行要求 |
| --- | --- |
| 例行检查 | 建议每 60 天检查接口、通风位置和附件连接状态，并清除表面灰尘 |
| 备份与恢复 | 恢复出厂设置前应导出配置包，文件校验码前缀为 BK109 |

## 5 故障诊断

| 现象 | 判断与处理 |
| --- | --- |
| 状态指示异常 | 指示灯红色闪烁三次后熄灭表示输出过流保护已触发 |
| 配置写入提示 | 状态灯黄色长亮 5 秒表示本地配置写入尚未完成，此时不得断电 |
| 设备无响应 | 从插座拔下并断开全部线缆 30 秒即可复位保护状态 |
| 连续启动失败 | 若连续 2 次启动失败，应断开外设并记录诊断编号 D218 后联系支持 |

## 6 保修与服务

充电器主体有限保修 18 个月，第三方线缆不在保修范围内。

送修时需同时提供设备序列号、购买凭证和最近一次日志包，服务受理代码为 SV508。

保修判定以检测记录为准，寄送前应移除个人账户、存储卡和可拆卸附件。

## 7 安全要求

**安全警告：不得接入旅行转换器的剃须刀专用口，也不得覆盖充电器散热。**

发现异味、异常发热、外壳变形或液体侵入时，应立即断电并停止继续测试。

如仍无法解决，请记录状态灯、错误码和操作步骤后联系人工支持。
